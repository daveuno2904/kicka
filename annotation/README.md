# Annotation

Tools and guidelines for manually annotating football match footage into
KICKA-formatted events.

This directory is a placeholder for v0.1. Planned contents:

- Annotation guidelines (how to identify event boundaries, assign coordinates, etc.)
- Annotator tooling / UI (if any)
- Inter-annotator agreement checks

See [`docs/standard/v0.1/`](../docs/standard/v0.1) for the event definitions that
annotations must conform to.
